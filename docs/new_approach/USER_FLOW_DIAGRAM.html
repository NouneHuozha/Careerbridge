Page-by-Page Details

PAGE 1: Landing
URL: /
Three entry doors. Door 1: "I'm not sure where to start" → Discovery. Door 2: "I want to browse on my own" → Browse all areas. Door 3: "I know what I'm looking for" → Search (coming soon).
PAGE 2: Discovery
URL: /discover
Two decisions on one page: Activity cards (pick 1-3 max) + Class selection (Class 10 / Class 12 / Another class / not sure). Button: "Show me options".
PAGE 3: Discovery Results
URL: /discover/results?class=[10|12|none]&picks=[ids]
Shows 2-3 curated career areas based on activity picks. Each card: "This area can connect to:" + relevant streams/courses. Button: "See study routes →". Bottom: "Show all areas", "Change my picks", "I'm still not sure → Guided Explorer".
PAGE 4: Stream/Course Detail
URL: /streams/[stream] OR /courses/[area]
Class 10: Stream paths (Medical line, Engineering line, Pure Science line). Class 12: Course types (Diploma, Degree, Certification). Each: entrance exam (verify), duration. Button: "See colleges →".
PAGE 5: College List
URL: /colleges?route=[route-slug]
College cards: Name, type badge, district, course offered, admission exam, fees status, hostel status, official website link, "Save this college" button.
PAGE 6: College Detail (FINAL)
URL: /college/[code]
Top section: Courses offered, Location, Admission & eligibility, Fees (verified/not), Official contact. Expandable sections: Hostel, Scholarships, Entrance exams, Admission details. "What's next?" box. Actions: Save college | Compare | Go back.
Key design rules: Every page has a back button + thread navigation so the student never feels lost. Counselling (Guided Explorer) is optional — Discovery works standalone. Activity picks are lightweight filters, not hidden matching algorithms. All fees/exams/college data shows "not verified" until confirmed with official sources.
