# Project Foundation

These documents define CareerBridge's approved product direction and system-level requirements.

| File | Responsibility |
|---|---|
| 01 | Vision, problem, scope and principles |
| 02 | Student/admin product requirements |
| 03 | Student journeys and navigation |
| 04 | High-level technical architecture |
| 05 | Data domains and governance |
| 06 | ML, LLM, RAG and XAI design |
| 07 | Admin Panel requirements |
| 08 | Delivery roadmap and acceptance gates |
| 09 | Decision log |
| 10 | Source collection and refresh operations |
| 11 | Security, privacy and quality assurance |
| 12 | Current implementation alignment and open decisions |

The foundation is authoritative for intended behaviour. Implementation documents specify how to realise it. If the code conflicts with the foundation, record the gap and align the code unless the product owner explicitly changes the decision.
