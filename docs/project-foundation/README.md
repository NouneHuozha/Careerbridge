## Authority and status
The agreed plan is the source of truth when current code conflicts with a documented decision. Preserve compatible implementation and realign conflicting code after inspection. Do not revise the product vision merely to fit existing implementation.

Use precise status language: **Agreed target** means approved direction; **Observed in repository** means code or configuration was found; **Tested** means a named check was actually run; **To verify** means further inspection/testing is required. Do not conflate these states.

## Core guardrails
Class 10 and Class 12 only; all-eight-Northeast-state institution architecture; Guide, Don't Decide; real sourced data as primary; clearly labelled demo/test data; controlled publication; student privacy; and honest implementation status.
