## Authority
These documents define the agreed target direction. They do not claim every described capability already exists in the repository. Existing code and older documents must be compared against this target.

When implementation conflicts with an explicit decision here, preserve compatible work and realign or replace conflicting work. Do not change the product vision merely to fit existing code. Older documents are retained as historical and implementation context.

Use these status terms:
- **Agreed target:** approved product or engineering direction.
- **Observed in repository:** identified in code or documentation; not necessarily tested.
- **To verify:** requires further inspection or testing.
- **Not established:** no confirmed implementation or decision.

Current guardrails: Class 10 and Class 12; institution coverage target is all eight Northeast states, with initial real collection allowed to start in Nagaland; Guide, don't decide; real sourced data is primary; demo/test data must be labelled and kept separate. The full core architecture includes structured recommendations, LLM + RAG, explainability, Admin/data governance and location-aware institution data.
