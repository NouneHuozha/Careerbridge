# CareerBridge

CareerBridge Next is a student-focused career and education exploration app. The current build contains the landing page and the Discovery page; verified course and college catalogue pages are not included yet.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run lint
npm run typecheck
npm run build
```

Project guidance for agents is in [AGENTS.md](./AGENTS.md). UI/UX references are in [docs/UI_UX_IMPROVEMENT_GUIDE.md](./docs/UI_UX_IMPROVEMENT_GUIDE.md). The optional VS Code MCP server configuration is in `.vscode/mcp.json`; the 21st server requires `API_KEY_21ST` in the environment.
